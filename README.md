   # Foodmart: Analytics Service

   - `analytics-service/`: Analytics Service (CodeIgniter 4). Dokumentasi lengkap ada di `analytics-service/README.md`.
   - `mock-services/`: service palsu untuk menguji Analytics tanpa menunggu service lain.
